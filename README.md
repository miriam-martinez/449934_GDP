This repository contains the main MATLAB codes used for the THEIA SBSA constellation design and EOL.
-> radar_tscan.m: is used for the evaluation of the number of RADAR satellites per orbit
-> radar_full.m: is used to analyse the performance of the full RADAR constellation with random debris generation
-> optical_full.m: same as radar_full.m but for the optical constellation
-> Fullconstellation.m: assesses the performance of both constellations with random debris populations
-> EOL.m: is used for the EOL strategy
-> Processing Folder: contains some of the simulation results and simulation processing codes to get to the report graphs.
